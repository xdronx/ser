# Furniture starter pack

This folder stores preloaded furniture assets for the MVP.

Files:
- `catalog.json` - metadata consumed by `/api/furniture`
- `furniture_pack.zip` - same set in a zip archive

For production use, replace placeholders with real transparent PNG assets:
- `chair.png`
- `sofa.png`
- `table.png`
- `lamp.png`
- `bed.png`
